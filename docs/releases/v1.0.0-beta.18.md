# Job Buddy v1.0.0-beta.18 — source beta

A local-first job-application dashboard built to replace the spreadsheet. Gmail updates, application stages, deadlines and saved salary evidence belong together in one place.

**This is a Windows developer-run source beta, not a finished installer release.** Windows and macOS one-click downloads are planned. The full macOS workflow is not supported yet.

## What's included

- Read-only Gmail scanning with incremental checks, recent-mail rechecks, partial-scan recovery and duplicate protection.
- Review email suggestions to create or update applications; save recruiter outreach separately from submitted applications.
- A stage-first Command Center with deadlines, notes, history, spreadsheet-style filtering and reviewed CSV/XLSX import/export.
- Inline salary evidence, compatible range blending, evidence confidence and attributed employee ratings. Tavily search is optional and requires your own key; results are not guaranteed salary estimates.
- Local profile and reviewed text-based PDF/DOCX resume import.
- Optional Chrome/Edge Browser Buddy with site-specific permission, approval-first autofill and no final application submission.
- Passphrase-encrypted workspace transfer, excluding credentials and original resume files.

## Before trying it

- Install a supported Node.js version and follow the [Windows quick start](https://github.com/yeebs1000/job-buddy/tree/codex/v1-private-public-repo-launch#windows-quick-start). The dashboard and companion run locally; never expose the companion to the internet.
- Gmail is **not yet a zero-setup public connector**. The distributed client ID is blank; developer/tester OAuth configuration is required. Public Google approval has not been verified. See [Gmail setup](https://github.com/yeebs1000/job-buddy/blob/codex/v1-private-public-repo-launch/docs/gmail-maintainer-setup.md). Testing projects require listed testers and may require reconnecting after seven days; publishing the source does not remove Google's restrictions.
- Keep the same browser and address to retain access to browser-local records. Export before clearing site data.
- Browser Buddy is an optional unpacked developer extension, not a store-installed extension. It never submits applications, handles credentials/CAPTCHA, or selects files for you.
- No AI model is connected. Ambiguous emails and weak research evidence still need review; unsupported form fields stay manual.

## Latest hardening

Production PDF resume import now loads its worker correctly from the companion server. Gmail connection-status reads now enforce the same dashboard-origin boundary as other private reads.

The [dated verification record](https://github.com/yeebs1000/job-buddy/blob/codex/v1-private-public-repo-launch/docs/releases/2026-09-30-production-audit.md) covers 881 unit tests, 30 dashboard tests, 5 extension tests and a separate web-core check. Those tests use synthetic data and do not prove real-provider or packaged-install acceptance. Two moderate transitive ExcelJS/uuid findings remain; no high/critical production findings were reported in that audit. Earlier timing-related test failures remain documented.
