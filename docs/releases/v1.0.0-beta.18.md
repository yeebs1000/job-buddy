# Job Buddy v1.0.0-beta.18

A Windows source beta for managing job applications in one local dashboard.

## Included

- Read-only Gmail scanning and reviewed application updates.
- An application overview with stages, deadlines, notes and history.
- Inline salary evidence, confidence and sourced company ratings.
- CSV/XLSX import/export and local profile with reviewed resume import.

## Start

Follow the [quick start](https://github.com/yeebs1000/job-buddy#get-started). Gmail requires [OAuth setup](https://github.com/yeebs1000/job-buddy/blob/feature/job-buddy-core/docs/gmail-maintainer-setup.md); web research uses your Tavily key.

## Next
